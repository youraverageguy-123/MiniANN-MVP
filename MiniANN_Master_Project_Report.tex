\section{Project Overview}

MiniANN is a modular, lightweight feed-forward Artificial Neural Network framework written from scratch in modern C++17/C++20. It deliberately uses no PyTorch, TensorFlow, Eigen, BLAS, or plotting libraries. The goal is architectural clarity, strict encapsulation, and clean object-oriented design --- not raw execution speed.

A user can:
\begin{enumerate}[itemsep=2pt]
    \item construct arbitrary layer topologies as \texttt{NeuralNetwork} $\to$ \texttt{Layer} $\to$ \texttt{Neuron},
    \item swap mathematical pieces at runtime through pure-virtual interfaces (\texttt{IActivation}, \texttt{ILoss}, \texttt{IOptimizer}, \texttt{IMetric}, \texttt{ILogger}, \texttt{IVisualizer}, \texttt{ILRScheduler}),
    \item train with mini-batch backpropagation (\texttt{Trainer::fit}) using Xavier/He initialisation, with support for $L_2$ weight decay, gradient norm clipping, and learning rate scheduling,
    \item load data from built-in logic gates or CSV files (\texttt{Dataset::loadCSV}, train/validation/test splits),
    \item evaluate binary and multi-class problems (threshold rule for one output, argmax otherwise, per-class precision/recall/F1),
    \item persist models as human-readable text (\texttt{MINIANN 1/2} format, 17-digit IEEE-754 precision),
    \item export loss curves and self-contained HTML reports with SVG charts,
    \item inspect network operations in real time through an interactive desktop workbench featuring both 2D analytics and a hardware-accelerated 3D OpenGL Network Viewer,
    \item prove correctness with gradient checks, serialisation round-trips, and AND/OR/XOR + Iris demos.
\end{enumerate}

Spec version: \textbf{1.3 / Problem Statement 5}. Language standard: \textbf{C++17/C++20} with \texttt{-Wall -Wextra -Wpedantic}, no raw \texttt{new}/\texttt{delete}, const-correctness, and the naming convention PascalCase classes / I-prefixed interfaces / camelCase methods / trailing \texttt{\_} members.

\subsection{Design rules enforced by the codebase}
\begin{itemize}[itemsep=2pt]
    \item \texttt{derivative(z)} takes the pre-activation $z$, not the output $a$.
    \item \texttt{Neuron::backward()} accumulates (\texttt{+=}); gradients are zeroed once per batch via \texttt{zeroGradients()}.
    \item \texttt{Layer::backward()} reads weights before the optimiser step.
    \item Serialiser tags (\texttt{sigmoid}, \texttt{tanh}, \texttt{relu}, \texttt{leaky\_relu}, \texttt{swish}, \texttt{elu}, \texttt{linear}, \texttt{softmax}) match \texttt{ActivationFactory::create()} exactly.
    \item The network never trains itself; \texttt{Trainer} + \texttt{IOptimizer} own mutation.
\end{itemize}

\section{Objectives and Scope}

\subsection{Objectives}
\begin{enumerate}[itemsep=2pt]
    \item Provide a readable, from-scratch neural-network implementation in which every backpropagation step is explicit (explicit loops, cached \texttt{lastInputs\_}/\texttt{lastZ\_}).
    \item Demonstrate textbook OOP: abstraction, inheritance, polymorphism, encapsulation, composition, plus the Strategy, Observer, Factory, Builder, Chain-of-Responsibility, Visitor, Composite, Fa\c{c}ade, and Memento patterns.
    \item Support real experiments without editing C++: CLI flags, an interactive REPL playground, CSV ingestion, and an interactive Qt GUI with 2D analytics and 3D spatial rendering over the same engine.
    \item Make every claim verifiable: gradient check (finite differences with relative error $< 10^{-7}$), serialisation round-trip, deterministic splits, and loss/accuracy artefacts (CSV + HTML).
\end{enumerate}

\subsection{Out of scope (by design)}
Convolutional/recurrent networks, GPU execution, and dynamic autograd graphs. The framework concentrates on feed-forward multi-layer perceptrons, transparent dense backpropagation, and rigorous architectural design.

\noindent
\textbf{Ownership rule:} \texttt{NeuralNetwork} owns forward/backward chaining only. \texttt{Trainer} + \texttt{IOptimizer} own the training policy and parameter mutation. \texttt{Dataset} owns data. \texttt{ILoss} / \texttt{IActivation} / \texttt{IMetric} / \texttt{ILogger} are pure interfaces. The UI never constructs datasets, networks, losses, or optimisers directly; it populates one \texttt{ExperimentConfig} and hands it to \texttt{ExperimentController}.

\subsection{Training pipeline (six steps)}
\begin{enumerate}[itemsep=2pt]
    \item \textbf{Data:} \texttt{Dataset::validate()} (dimensions, NaN/Inf), optional deterministic splitting (\texttt{splitTrainValTest()}); normalisation strategies via \texttt{INormalizer} and polymorphic sourcing via \texttt{IDatasetSource}.
    \item \textbf{Build:} \texttt{NeuralNetwork} assembles \texttt{Layer} objects of \texttt{Neuron} units; \texttt{ActivationFactory::create(name)} supplies the non-linearity; initialisation strategies apply He or Xavier limits.
    \item \textbf{Train:} \texttt{Trainer::fit()}: shuffle with mt19937 seed, mini-batch partition, per-batch \texttt{zeroGradients()}, per-sample \texttt{predict} $\to$ \texttt{loss.gradient()} $\to$ \texttt{backward()} (accumulates \texttt{gradW += delta*a}).
    \item \textbf{Regularise \& Clip:} Add $L_2$ penalty to weight gradients ($\mathbf{g}_W \mathrel{+}= \lambda \mathbf{W}$) and rescale global gradient norm if $\|g\|_2 > g_{\max}$.
    \item \textbf{Optimise:} Execute \texttt{optimizer.step(net, B)} with learning rate scheduling.
    \item \textbf{Evaluate \& Persist:} Compute accuracy and confusion matrices; stream metrics to observers; persist weights via \texttt{ModelSerializer} or export standalone HTML reports.
\end{enumerate}

\section{Features in Detail}

\subsection{Network construction}
Networks are composed, not inherited: \texttt{NeuralNetwork} holds \texttt{std::vector<Layer>}, and each \texttt{Layer} holds \texttt{std::vector<Neuron>}. Topology dimensions are strictly validated; invalid layer dimensions throw \texttt{std::invalid\_argument}. Hidden layers accept a \texttt{fanOut} parameter to scale Xavier/He variance limits accurately.

\subsection{Activation functions (8)}
\texttt{IActivation} declares \texttt{activate(z)}, \texttt{derivative(z)} (at pre-activation $z$), \texttt{name()}, and \texttt{isVector()} (false except Softmax). Concrete classes:
\begin{itemize}[itemsep=1pt]
    \item \textbf{Sigmoid:} $\sigma(z) = \frac{1}{1 + e^{-z}}$, with derivative $\sigma(z)(1 - \sigma(z))$.
    \item \textbf{Tanh:} $\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}$, with derivative $1 - \tanh^2(z)$.
    \item \textbf{ReLU:} $\max(0, z)$, with derivative $1$ for $z > 0$, $0$ otherwise.
    \item \textbf{LeakyReLU:} $\max(\alpha z, z)$ with validated $\alpha \in (0, 1)$, default $0.01$.
    \item \textbf{Swish:} $z \cdot \sigma(z)$, with smooth analytic derivative $\sigma(z) + z\sigma(z)(1 - \sigma(z))$.
    \item \textbf{ELU (Exponential Linear Unit):} $z$ for $z > 0$, and $\alpha(e^z - 1)$ for $z \le 0$ ($\alpha = 1.0$), avoiding dying neurons by allowing negative saturation.
    \item \textbf{Linear:} $f(z) = z$, $f'(z) = 1$ for regression output heads.
    \item \textbf{Softmax:} Joint stable operator $\frac{e^{z_i - \max(z)}}{\sum e^{z_j}}$ evaluated at layer level with Jacobian backpropagation.
\end{itemize}

\subsection{Loss functions (3)}
\texttt{ILoss} declares \texttt{compute(pred, target)} and \texttt{gradient(pred, target)}.
\begin{itemize}[itemsep=1pt]
    \item \textbf{MSELoss:} Mean Squared Error $\frac{1}{2n}\sum (y_i - \hat{y}_i)^2$, default for regression and general heads.
    \item \textbf{BCELoss:} Binary Cross-Entropy with numerical clamping $[\epsilon, 1-\epsilon]$, rejecting multi-output targets.
    \item \textbf{CCELoss:} Categorical Cross-Entropy for one-hot multi-class classification, ensuring proper probability penalisation.
\end{itemize}

\subsection{Optimisers (4)}
\texttt{IOptimizer} declares \texttt{step(net, batchSize)}, \texttt{visit(visitor)}, and \texttt{name()}.
\begin{itemize}[itemsep=1pt]
    \item \textbf{SGD:} Standard mini-batch gradient descent $\theta \leftarrow \theta - \frac{\eta}{B} g$.
    \item \textbf{Momentum:} Classical momentum maintaining velocity buffer $v \leftarrow \mu v - \frac{\eta}{B} g$.
    \item \textbf{Adam:} Adaptive moment estimation tracking first ($m_t$) and second ($v_t$) moments with bias correction $\hat{m}_t, \hat{v}_t$.
    \item \textbf{RMSprop:} Exponentially decaying average of squared gradients $v_t \leftarrow \alpha v_{t-1} + (1-\alpha)g_t^2$, dividing updates by $\sqrt{v_t + \epsilon}$.
\end{itemize}

\subsection{Training engine \& regularisation}
\texttt{Trainer::fit()} manages the epoch loop. Key capabilities include:
\begin{itemize}[itemsep=1pt]
    \item \textbf{$L_2$ Weight Decay:} Adds $\lambda \mathbf{W}$ to gradients prior to optimiser step to penalise large weights.
    \item \textbf{Gradient Norm Clipping:} Computes total Frobenius norm $\|g\|_2 = \sqrt{\sum \|g_W\|_F^2 + \sum \|g_b\|_2^2}$ and rescales gradients if $\|g\|_2 > g_{\max}$.
    \item \textbf{Learning Rate Schedulers:} Modulates $\eta$ per epoch using \texttt{StepLR} or \texttt{ExponentialLR}.
\end{itemize}

\subsection{Datasets and preprocessing}
\texttt{Dataset} stores parallel inputs and targets. Supports CSV ingestion (\texttt{Dataset::loadCSV}), RFC-4180 parsing, and deterministic 3-way partitioning (\texttt{splitTrainValTest}). Preprocessing includes \texttt{ZScoreNormalizer}, \texttt{MinMaxNormalizer}, and one-hot target encoding.

\subsection{Metrics, persistence and export}
\begin{itemize}[itemsep=1pt]
    \item \textbf{Metrics:} \texttt{Accuracy} and \texttt{ConfusionMatrix} providing per-class precision, recall, and F1-score.
    \item \textbf{Persistence:} \texttt{ModelSerializer} writes human-readable \texttt{MINIANN 1/2} formats at 17-digit precision, capturing layer topology, weights, and optimiser momentum states.
    \item \textbf{Export:} \texttt{CSVLossExporter} exports training trajectories; \texttt{HtmlReportBuilder} generates standalone interactive HTML reports with inline SVG charts.
\end{itemize}

\subsection{Interactive 2D \& 3D visual front-ends}
\begin{itemize}[itemsep=1pt]
    \item \textbf{CLI Demos:} \texttt{xor\_demo}, \texttt{and\_or\_demo}, \texttt{iris\_demo}, \texttt{compare\_demo}, and the interactive REPL \texttt{playground}.
    \item \textbf{Qt6 Workbench (\texttt{gui\_qt}):} Real-time training dashboard with loss curves, accuracy plots, decision boundary heatmaps, confusion matrix modal, and dataset partition cards.
    \item \textbf{3D OpenGL Network Viewer:} Integrated hardware-accelerated 3D visualisation module (\texttt{Network3DWidget}) with interactive orbit/pan/zoom camera, dynamic edge magnitude thresholding, layer focus isolation, and individual neuron picking.
\end{itemize}

\subsection{Detailed Analysis of Selected Patterns}

\subsubsection{Strategy Pattern (\texttt{IOptimizer}, \texttt{IActivation}, \texttt{INormalizer})}
The training engine relies on the Strategy pattern to decouple optimisation algorithms from the backpropagation traversal. The \texttt{Trainer} holds an \texttt{IOptimizer\&} reference. When \texttt{optimizer.step(net, batchSize)} is invoked, polymorphism directs execution to the selected algorithm (e.g., \texttt{RMSprop::step} or \texttt{Adam::step}), updating parameters without branching logic inside the trainer.

\subsubsection{Observer Pattern (\texttt{TrainingCallback}, \texttt{LiveBridge})}
During iterative training, decoupling telemetry from computational math is paramount. \texttt{Trainer::fit} accepts an optional \texttt{TrainingCallback*} observer. At the conclusion of each epoch, it invokes \texttt{callback->onEpoch(epoch, history)}. Concrete observers such as \texttt{LiveConsole} render ASCII curves, while the Qt workbench's bridge queues thread-safe snapshots for 2D and 3D rendering.

\subsubsection{Visitor Pattern (\texttt{INetworkVisitor})}
To perform non-intrusive operations across the network structure (such as serialisation formatting, statistics collection, or parameter decay), \texttt{NeuralNetwork} implements \texttt{accept(INetworkVisitor\& visitor)}. The visitor visits each layer and neuron sequentially, separating operational algorithms from the network data structure.

\section{Dynamic View \& Concrete Dry Run Trace}

\subsection{Per-batch training sequence}
The execution order within each batch strictly enforces mathematical invariants:
\begin{enumerate}[itemsep=2pt]
    \item \texttt{net.zeroGradients()} zeroes accumulated weight and bias gradients across all layers.
    \item For each sample:
    \begin{itemize}[itemsep=1pt]
        \item \texttt{net.predict(x)} executes forward propagation, caching inputs $a^{[l-1]}$ and pre-activations $z^{[l]}$.
        \item \texttt{loss.gradient(pred, target)} computes output error derivative $\nabla_{\hat{y}}\mathcal{L}$.
        \item \texttt{net.backward(dL/dOut)} propagates deltas backward, accumulating gradients: $\mathbf{g}_W \mathrel{+}= \boldsymbol{\delta} \mathbf{a}^T$, $g_b \mathrel{+}= \delta$.
    \end{itemize}
    \item \textbf{Regularisation:} If $\lambda > 0$, add $L_2$ weight penalty to accumulated gradients.
    \item \textbf{Grad Clipping:} If enabled, evaluate $\|g\|_2$; scale down if norm exceeds threshold.
    \item \texttt{optimizer.step(net, B)}: Optimiser updates weights using averaged gradients $\frac{1}{B} \mathbf{g}$. Crucially, weights are read before mutation, ensuring subsequent layer backward passes are mathematically untainted.
\end{enumerate}

\subsection{Concrete mathematical trace for 1 dry run}
We trace a complete forward and backward step on a $2 \to 2 \to 1$ network solving XOR.
\begin{itemize}[itemsep=1pt]
    \item \textbf{Sample:} $\mathbf{x} = [0.0, 1.0]^T$, Target $y = 1.0$.
    \item \textbf{Hidden Layer 1 ($\tanh$):}
    $\mathbf{W}^{[1]} = \begin{bmatrix} 0.5 & -0.2 \\ -0.4 & 0.8 \end{bmatrix}, \quad \mathbf{b}^{[1]} = \begin{bmatrix} 0.1 \\ -0.1 \end{bmatrix}$.
    \item \textbf{Output Layer 2 ($\sigma$):}
    $\mathbf{W}^{[2]} = \begin{bmatrix} 0.7 & -0.5 \end{bmatrix}, \quad b^{[2]} = 0.2$.
    \item \textbf{Optimiser:} RMSprop with $\eta = 0.1$, decay $\alpha = 0.9$, $\epsilon = 10^{-8}$, initial second moments $v_0 = 0$.
\end{itemize}

\subsubsection{Step 1: Forward Propagation}
\begin{align*}
    \mathbf{z}^{[1]} &= \mathbf{W}^{[1]} \mathbf{x} + \mathbf{b}^{[1]} = \begin{bmatrix} 0.5(0) - 0.2(1) + 0.1 \\ -0.4(0) + 0.8(1) - 0.1 \end{bmatrix} = \begin{bmatrix} -0.1000 \\ 0.7000 \end{bmatrix} \\
    \mathbf{a}^{[1]} &= \tanh(\mathbf{z}^{[1]}) = \begin{bmatrix} \tanh(-0.1000) \\ \tanh(0.7000) \end{bmatrix} = \begin{bmatrix} -0.0997 \\ 0.6044 \end{bmatrix} \\
    z^{[2]} &= \mathbf{W}^{[2]} \mathbf{a}^{[1]} + b^{[2]} = 0.7(-0.0997) - 0.5(0.6044) + 0.2 = -0.1720 \\
    a^{[2]} &= \sigma(z^{[2]}) = \frac{1}{1 + e^{0.1720}} = 0.4571 \\
    \mathcal{L}_{\text{MSE}} &= \frac{1}{2}(a^{[2]} - y)^2 = \frac{1}{2}(0.4571 - 1.0)^2 = 0.1474
\end{align*}

\subsubsection{Step 2: Backward Propagation}
\begin{align*}
    \sigma'(z^{[2]}) &= a^{[2]}(1 - a^{[2]}) = 0.4571(1 - 0.4571) = 0.2482 \\
    \delta^{[2]} &= (a^{[2]} - y) \cdot \sigma'(z^{[2]}) = (-0.5429) \cdot 0.2482 = -0.1347 \\
    \frac{\partial \mathcal{L}}{\partial \mathbf{W}^{[2]}} &= \delta^{[2]} (\mathbf{a}^{[1]})^T = -0.1347 \cdot [-0.0997, \ 0.6044] = [0.0134, \ -0.0814] \\
    \frac{\partial \mathcal{L}}{\partial b^{[2]}} &= \delta^{[2]} = -0.1347
\end{align*}
Propagating delta to hidden layer:
\begin{align*}
    \tanh'(\mathbf{z}^{[1]}) &= 1 - (\mathbf{a}^{[1]})^2 = \begin{bmatrix} 1 - (-0.0997)^2 \\ 1 - (0.6044)^2 \end{bmatrix} = \begin{bmatrix} 0.9901 \\ 0.6347 \end{bmatrix} \\
    \boldsymbol{\delta}^{[1]} &= \left( (\mathbf{W}^{[2]})^T \delta^{[2]} \right) \odot \tanh'(\mathbf{z}^{[1]}) = \begin{bmatrix} 0.7(-0.1347) \cdot 0.9901 \\ -0.5(-0.1347) \cdot 0.6347 \end{bmatrix} = \begin{bmatrix} -0.0934 \\ 0.0428 \end{bmatrix} \\
    \frac{\partial \mathcal{L}}{\partial \mathbf{W}^{[1]}} &= \boldsymbol{\delta}^{[1]} \mathbf{x}^T = \begin{bmatrix} -0.0934 \\ 0.0428 \end{bmatrix} [0.0, \ 1.0] = \begin{bmatrix} 0.0 & -0.0934 \\ 0.0 & 0.0428 \end{bmatrix}, \quad \frac{\partial \mathcal{L}}{\partial \mathbf{b}^{[1]}} = \begin{bmatrix} -0.0934 \\ 0.0428 \end{bmatrix}
\end{align*}

\subsubsection{Step 3: RMSprop Parameter Update}
For output weight $W_{1,2}^{[2]}$ (prior value $-0.5$, gradient $g = -0.0814$):
\begin{align*}
    v_1 &= \alpha v_0 + (1 - \alpha) g^2 = 0.9(0) + 0.1(-0.0814)^2 = 0.0006626 \\
    W_{1,2}^{[2]\,\text{new}} &= -0.5 - \frac{\eta}{\sqrt{v_1 + \epsilon}} g = -0.5 - \frac{0.1}{\sqrt{0.0006626 + 10^{-8}}} (-0.0814) = -0.5 + 0.3162 = -0.1838
\end{align*}
The adaptive learning rate applies a corrective step of $+0.3162$, shifting the weight rapidly toward minimizing the classification error.

\section{Minimal Usage Example}

The following self-contained listing demonstrates training XOR from scratch in approximately 30 lines:

\begin{lstlisting}
#include "miniann/miniann.hpp"
#include <random>

using namespace miniann;

int main() {
    std::mt19937 rng(42);
    Dataset data = makeXorGate();

    NeuralNetwork net;
    net.addLayer(Layer(4, 2, ActivationFactory::create("tanh"), rng, WeightInit::Xavier));
    net.addLayer(Layer(1, 4, ActivationFactory::create("sigmoid"), rng, WeightInit::Xavier));

    auto loss = LossFactory::create("mse");
    auto opt  = OptimizerFactory::create("rmsprop", 0.01);
    ConsoleLogger logger;

    Trainer trainer(net, *loss, *opt, &logger);
    TrainingConfig cfg;
    cfg.epochs = 1500;
    cfg.batchSize = 1;
    cfg.weightDecay = 0.0001;
    cfg.gradClip = 1.0;

    TrainingHistory h = trainer.fit(data, nullptr, cfg);
    CSVLossExporter::exportHistory(h, "xor_loss.csv");
    ModelSerializer::save(net, "xor.model");

    Vector pred = net.predict({1.0, 0.0}); // Outputs ~1.0
    return 0;
}
\end{lstlisting}

\section{Conclusion}

MiniANN demonstrates that a complete neural-network simulation laboratory --- dense layers, eight activations, three loss functions, four optimisers, regularisation, gradient norm clipping, metrics, file persistence, terminal visualization, HTML reports, and an interactive desktop workbench featuring both 2D analytics and hardware-accelerated 3D OpenGL network rendering --- fits cleanly into dependency-free C++17/C++20 when structured around disciplined object-oriented programming.

The strict encapsulation of mathematical invariants, coupled with flexible GoF design patterns (Strategy, Observer, Factory, Builder, Chain of Responsibility, Visitor, Composite, Fa\c{c}ade, and Bridge), produces an architecture that is simultaneously mathematically verifiable, highly extensible, and straightforward to inspect.
